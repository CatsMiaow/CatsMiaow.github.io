청소

입력한 개수 범위 내의 채팅 메시지를 삭제합니다.

주의

⚙서버 설정 > 연동 > 봇과 앱 > 마냥 클릭(관리) > 명령어에서 개별 역할 설정으로 청소 명령어를 특정 역할만 제한해야 사용할 수 있습니다.
사용자가 메시지 관리 권한이 있으면 제한에 걸리지 않습니다.

  • 봇이 메시지 관리 권한이 있어야 합니다.
  • 삭제한 메시지는 복구할 수 없으며, 2주 이상 지난 메시지는 삭제되지 않습니다.
  • 채널의 전체 메시지를 삭제하려면 디스코드의 채널 복제하기로 채널을 재생성하고 기존 채널을 삭제하세요.
  • /청소 개수 유저|태그|메시지|응답삭제?
    • 명령어를 입력한 유저가 채널에서 메시지 관리 권한이 없으면 본인의 메시지만 삭제합니다.
    • 20개를 지정하면 최근 메시지 20개 중에 본인이 작성한 메시지만 삭제합니다.
    • 채널에서 메시지 관리 권한이 있을 때 유저 또는 태그 옵션으로 청소할 유저를 지정할 수 있습니다.
      • 20개를 지정하면 최근 메시지 20개 중에 입력한 유저가 작성한 메시지만 삭제합니다.
    • 메시지 옵션은 특정 메시지ID를 입력하여 해당 메시지 다음(아래)에 오는 메시지만 삭제합니다.
      • 메시지 삭제의 시작 지점을 지정하는 것과 같습니다.
      • 메시지 옵션과 대상 지정(유저 또는 태그) 옵션은 같이 사용할 수 있습니다.
    • 응답삭제 옵션은 봇이 응답하는 청소 결과 메시지를 5초 뒤에 자동으로 삭제합니다.
      • 채널에서 메시지 관리 권한이 있는 유저만 사용할 수 있습니다.
/청소 개수:50
/청소 개수:25 유저:@테스트
/청소 개수:75 태그:테스트#1234
/청소 개수:10 메시지:123456789876543210
/청소 개수:2 응답삭제:True
